## ✨ Key Features

- Interactive Canvas Background: Dynamic constellation particle network with mouse repulsion & parallax interaction.
- Dynamic Typing Hero: Smooth text animation cycling through modern developer specializations.
- Live Project Filtering: Interactive category tabs (All, React, JavaScript, Landing Page) with smooth transitions.
- Glassmorphic Modern UI: Dark aesthetic with subtle neon cyan & violet glow effects and backdrop blur.
- Direct Resume Download: One-click CV download button directly from the navigation bar.
- Interactive Contact Form: Built-in form validation with custom service selector.
- 100% Responsive Design: Tailored for seamless viewing on desktops, tablets, and smartphones.
